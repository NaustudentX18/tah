# TAH M0 vs M1

## M0 — Shell (this milestone)

Ship a navigable Compose app with Signal Deck chrome and no live agent runtime.

| Area | M0 |
|------|----|
| Home | Session Board (Working / Needs you / Done) |
| Detail | Timeline/stream stub + ToolCard / PermissionCard chrome |
| Dispatch | Prompt / skill / model / budget form stubs |
| Providers | BYOK + Ollama placeholder cards |
| Skills | Stub screen |
| Settings | Permission mode, Touch Steer\|Keys, notifications, about |
| Theme | Signal Deck tokens (primary `#2EE6D6`, surfaces, needsYou / success / reject) |
| Identity | `app.tah.shell` — **no** OFH / `com.ofh` |

## M1 — Runtime wire-up (next)

- Live session list + Needs-you badge counts
- Stream / event timeline from agent runtime
- Real tool + permission ship-gates
- Provider key storage + Ollama discovery
- Skills pack load / memory lanes
- Dispatch enqueue + budget metering
